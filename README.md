# Programimi në WWW: repository individual

Detyrat javore të lëndës *Programimi në WWW* (FShMN). Çdo javë ka folderin e vet
`JavaI` … `JavaXIV`; folderët ende bosh mbahen me `.gitkeep`.

## GitHub Pages

🌐 **[Hap faqen e detyrave javore](https://gjergjquni.github.io/fshmn-programiminewww-gjergjquni/)**

Kjo faqe në GitHub Pages shërben për t’i parë dhe hapur lehtësisht detyrat e dorëzuara
gjatë javëve të lëndës.
